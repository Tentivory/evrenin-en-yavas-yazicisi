# Evrenin En Yavaş Yazıcısı

## Neden Var?

Çünkü hız kötüdür. Hız sizi stres yapar. Bu program size sabrı öğretir. Her harfi 0.5 saniye bekleyerek yazar. Bu sürede siz de hayata dair derin düşünceler edinebilirsiniz (veya uykuya dalabilirsiniz).

Bu, modern teknolojinin anti-tezidir. GitHub Copilot bile bu kadar yavaş düşünemez.

## Kullanım

```bash
python yavas_yazici.py
```

Sonra bekleyin. Çok bekleyin. Daha çok bekleyin.

## Özellikler

- Her harf için 500ms gecikme
- Sonsuz sabır gerektirir
- Hiçbir şeyi acele ettirmez
- Patates yasaklıdır
